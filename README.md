# rkg-armory

Android tablet application for managing diving-club equipment.

## Current prototype

- Responsive portrait and landscape tablet layout
- Material 3 interface
- One-tap prototype login
- Home dashboard
- Adaptive navigation for loans, equipment, and inventory
- Searchable member selection and equipment issuance keypad
- Light and dark themes
- Fully local; no network connection required

## Run

1. Open this directory in Android Studio.
2. Let Gradle sync and install Android SDK 36 if prompted.
3. Run on an Android tablet or emulator.

JDK 17 is required. Android Studio includes a compatible JDK.
